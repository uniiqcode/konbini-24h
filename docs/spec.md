# 仕様（2026-11-07 決定、同日にきつめの条件とタグを追加）

## 目的

バズっている日本のコンビニのショート動画を、日本を含む世界の人に紹介する。

## 対象のコンビニ

**セブン-イレブン・ファミリーマート・ローソンの3社**に絞る。ほかの店（ミニストップ・セイコーマートなど）や、ほかの国のコンビニ（韓国の GS25 など）の動画は載せない。

## 言語

スマホの言語設定（`navigator.languages`）でページの言語を切り替える。ページは1つで、画面の隅に切り替えのボタンを置き、選んだ言語はそのスマホのブラウザに覚えさせる。

| スマホの言語 | 表示 | タイトル |
|---|---|---|
| `ja` | 日本語 | バズってるコンビニ動画 |
| `ko` | 韓国語 | 일본 편의점 인기 쇼츠 |
| `zh-TW`・`zh-Hant`・`zh-HK` | 繁体字の中国語（台湾） | 日本超商爆紅短影音 |
| それ以外（`zh-CN` も） | 英語 | Viral Japan Konbini Shorts |

- ロゴは全言語で共通。タイトル・見出し・分類の名前・説明は各言語で用意し、文章は1〜2行に収める
- 動画のタイトルは翻訳しない（AI・翻訳の API は使わない）。元の言語のまま出し、言語のバッジを付ける
- **動画の言語で絞り込むメニューは作らない**（どの言語の人にも、すべての言語の動画を見せる。2026-11-07 決定）
- そのかわり、タイトルの言葉から**中身のタグ**（「ラーメン」「アイス」「大食い」など）を付け、視聴者の言語で出す（下の「タグ」）

## 載せる動画（バズの基準）

`config/rules.toml` の `[buzz]` で変えられる。

| 項目 | 値 |
|---|---|
| 長さ | 3分以下（今の YouTube ショートの上限） |
| 投稿 | 90日以内 |
| 再生数 | **30万回以上**。ただし投稿から14日以内の動画は、**1日あたり3万回以上**なら30万回に届かなくても載せる（2026-11-13 追加） |
| 分類 | **食品だけ**（食品以外・未分類は載せない） |
| 公式チャンネル | **載せない**（ほぼ広告のため。`official_channels`） |
| 1チャンネルの上限 | **5本まで**（再生数の多い順に残す。少数のチャンネルに偏るため） |

さらに、次をすべて満たすものだけ載せる。

- **タイトル**（ハッシュタグを含む）に3社の名前か「コンビニ」にあたる言葉がある。概要欄にだけ店名がある動画は、関係ないものが多いので載せない
- 日本の話だと分かる（タイトルか概要欄に「日本」「Japan」「일본」などがある、またはタイトルにかながある）。7-Eleven とファミリーマートは韓国・台湾・タイにもあるため
- ほかの店の名前や除外の言葉（広告の「PR」表記を含む）がタイトルにない。`data/exclude.txt` に書いた動画（人が外したもの）でもない

## 分類

キーワード（タイトル → 概要欄の順）で決める。AI は使わない。キーワードは `config/rules.toml`。

**店**

| キー | 日本語 | 韓国語 | 繁体字 | 英語 |
|---|---|---|---|---|
| seven | セブン-イレブン | 세븐일레븐 | 7-ELEVEN | 7-Eleven |
| familymart | ファミリーマート | 패밀리마트 | 全家 | FamilyMart |
| lawson | ローソン | 로손 | LAWSON | Lawson |

## タグ（中身の紹介）

`config/tags.toml` の辞書で、タイトル（ハッシュタグを含む）の言葉から付ける。1本に、もの（ラーメン・弁当・アイス・チョコなど30）から2つ、内容（ランキング・食べ比べ・大食い・話題・コラボ・レビュー・新商品など11）から1つまで。ラベルは日本語・韓国語・繁体字・英語。

試しの81本では、80本にタグが付き、57本に「もの」のタグが付いた。

## 検索対策（SEO、2026-11-07 決定）

無料の範囲で行う。手順と、業スー酒場と共有する課題と解決の記録は、claude-skills の **`seo-uniiqcode`** スキルにまとめてある（業スー酒場で先に実装し、分かったことをここに取り入れる）。

- **正式な URL は `https://uniiqcode.com/konbini-24h/`**（2026-11-08。uniiqcode の GitHub Pages が独自ドメイン uniiqcode.com になった）。`canonical`・`hreflang`・サイトマップ・OGP の URL はすべてこちらで書く

- **言語ごとに別の URL**: `/ja/`・`/ko/`・`/zh-tw/`・`/en/` の4ページを、毎日の更新で作る。一番上の `/` に来た人だけ、スマホの言語で振り分ける（切り替えのボタンも残す）。各ページに `hreflang`（4言語＋`x-default` は英語）を入れる
- **動画の一覧は HTML に書き込んで作る**（JavaScript で後から描かない）。絞り込み・並べ替えは JavaScript で行ってよい
- META タグ: 言語ごとのタイトルと説明文、`lang`、`canonical`
- SNS の共有（OGP・X のカード）: 背景の絵・タイトル・説明
- `sitemap.xml`（4言語、`hreflang` と更新日つき）と `robots.txt`
- 構造化データ（JSON-LD）: 動画の一覧（`ItemList` と `VideoObject`）
- 表示の速さ: 背景の絵は WebP、1枚目だけ先に読み込み、残りの絵とサムネイルは後から読み込む
- 公開したら人が登録する: Google Search Console・Bing Webmaster Tools・Naver Search Advisor（韓国）
- 公開前にリポジトリの名前を変える（URL に konbini を入れる。公開後に URL を変えると検索の評価が振り出しに戻るため）
- **店ごと・分類ごとのページ**（毎日の更新で自動で作る。人の作業は増えない）
  - 店ごと: セブン-イレブン・ファミリーマート・ローソン・全店の4ページ × 4言語
  - 分類ごと: 動画が **10本以上** ある分類だけ自動で作る（中身の少ないページを作らないため）。10本を下回ったらページを外す
  - 店×分類の組み合わせのページは作らない

## 訪問者数のカウンター（2026-11-07 決定）

- ページの最後に、これまでの**訪問者数**（同じ人が1日に何回見ても1人）と、**上位10か国**の内訳を出す。11か国目からは「ほか○か国」
- 数えるのは **GoatCounter**（無料のアクセス解析。個人・非商用は無料。Cookie を使わない）。ページに GoatCounter の計測用コードを入れる
- 国別の数は、毎朝の自動更新（GitHub Actions）で GoatCounter の API から受け取り、ページに書き込む（ページを作った時点までの数。作った日の「○月○日時点」と書く）。API トークンは GitHub の Secrets に入れ、ページには出さない
- 国の名前は、見ている人の言語で出す（ブラウザの `Intl.DisplayNames` を使う。翻訳を用意しない）。国旗の絵文字を添える
- ページの最後に「訪問者数は GoatCounter で数えています（個人を特定する情報は保存しません）」と各言語で1行書く
- 人の作業（制作の時）: GoatCounter に登録してサイトのコード（例: `konbini24h`）を決め、API トークンを作って Secrets に入れる

## ページ上部・ロゴ・見せ方（2026-11-09 決定）

- **ロゴ**: ページ上部は **A（看板そのまま）**: 白い看板の上に KONBINI、下のからし色の帯に 24H（2026-11-10: 2段の文字を同じ大きさに）。ホーム画面のアイコンは **C（正方形）**: **KON / BINI / 24H の3段**。横長のロゴと同じ2色で、上の白に KON・BINI、下のからし色に 24H（BINI と 24H のあいだを少し広く開けて色を分ける）。3段とも同じ文字の大きさで、アイコンに収まる範囲でいちばん大きく（2026-11-10 に変更）。タブの小さいアイコンは 24H だけ（`design/logo-candidates.html`）。色はからし色 #E5B000 と墨色 #1C2127。からし色の上の文字は墨色。文字は線（アウトライン）にした画像にする
- **背景のスライドショー**: 東京 → 京都 → 富士山 → 坂道 の順に、6秒ごとにふわっと重ねて切り替える。画面の動きを減らす設定（`prefers-reduced-motion`）の端末では自動で切り替えず、指で送る。京都と坂道は見せる位置を左寄りにする（人物が左寄りのため）。1枚目だけ先に読み込み、残りは後から読み込む

- **スライドに添える言葉**: 1枚ごとに込めた思いを短く出す（各言語）。例: 東京「夜中の2時でも開いている」、京都「京都の町にも似合う」、富士山「旅の途中に、ふらっと」、坂道「いつもの帰り道に」（文言は作る時に4言語で整える）
