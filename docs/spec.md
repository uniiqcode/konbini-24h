# 仕様（2026-11-07 決定）

## 目的

バズっている日本のコンビニのショート動画を、日本を含む世界の人に紹介する。

## 対象のコンビニ

**セブン-イレブン・ファミリーマート・ローソンの3社**に絞る。ほかの店（ミニストップ・セイコーマートなど）や、ほかの国のコンビニ（韓国の GS25 など）の動画は載せない。

## 言語

スマホの言語設定（`navigator.languages`）でページの言語を切り替える。ページは1つで、画面の隅に切り替えのボタンを置き、選んだ言語はそのスマホのブラウザに覚えさせる。

| スマホの言語 | 表示 | タイトル |
|---|---|---|
| `ja` | 日本語 | バズってるコンビニ動画 |
| `ko` | 韓国語 | 일본 편의점 인기 쇼츠 |
| `zh-TW`・`zh-Hant`・`zh-HK` | 繁体字の中国語（台湾） | 日本超商爆紅短影音 |
| それ以外（`zh-CN` も） | 英語 | Viral Japan Konbini Shorts |

- ロゴは全言語で共通。タイトル・見出し・分類の名前・説明は各言語で用意し、文章は1〜2行に収める
- 動画のタイトルは翻訳しない（AI・翻訳の API は使わない）。元の言語のまま出し、言語のバッジを付ける

## 載せる動画（バズの基準）

`config/rules.toml` の `[buzz]` で変えられる。

| 項目 | 値 |
|---|---|
| 長さ | 3分以下（今の YouTube ショートの上限） |
| 投稿 | 90日以内 |
| 再生数 | 10万回以上 |

さらに、次をすべて満たすものだけ載せる。

- **タイトル**（ハッシュタグを含む）に3社の名前か「コンビニ」にあたる言葉がある。概要欄にだけ店名がある動画は、関係ないものが多いので載せない
- 日本の話だと分かる（タイトルか概要欄に「日本」「Japan」「일본」などがある、またはタイトルにかながある）。7-Eleven とファミリーマートは韓国・台湾・タイにもあるため
- ほかの店の名前や除外の言葉がタイトルにない。`data/exclude.txt` に書いた動画（人が外したもの）でもない

## 分類

キーワード（タイトル → 概要欄の順）で決める。AI は使わない。キーワードは `config/rules.toml`。

**店**

| キー | 日本語 | 韓国語 | 繁体字 | 英語 |
|---|---|---|---|---|
| seven | セブン-イレブン | 세븐일레븐 | 7-ELEVEN | 7-Eleven |
| familymart | ファミリーマート | 패밀리마트 | 全家 | FamilyMart |
| lawson | ローソン | 로손 | LAWSON | Lawson |
| all | 全店 | 전체 | 全部 | All stores |

1社だけの名前があればその店。2社以上、または店名がなく「コンビニ」だけなら全店。絞り込みで1社を選んだ時は、その店の動画に加えて全店の動画も出す（未決: 出さない案もある）。

- どれにも当たらないものは「未分類」。ページでは「すべて」の中にだけ出す

## 並べ替え

**新しい順**（投稿日）と **再生数の多い順** を切り替える。最初は再生数の多い順（未決）。

## 1本ごとの表示

サムネイル（YouTube が配っている画像 `https://i.ytimg.com/vi/<ID>/...` をそのまま表示し、コピーして置かない）・タイトル・チャンネル名・再生数・投稿日・店・分類・言語のバッジ。押すと YouTube を開く。

## 更新

- 毎日 GitHub Actions で集めて `data/videos.json` を作り直し、ページを公開する（GitHub Pages）
- 載っている動画の再生数も毎日取り直す（YouTube API の規約で、保存した統計は30日以内に取り直す）。基準から外れた動画（90日を過ぎたもの）は落ちる
- **自動で反映する**（PR を通さない）。外したい動画は人が `data/exclude.txt` に ID を書く
- API の使用量は1日約2,400ユニット（検索24回＋詳細の取得）

## 公開とキー

- GitHub Pages を無料で使うため、リポジトリを public にする（ページを公開する時に人が切り替える）
- YouTube API のキーは、毎日の自動収集の前に **別の Google Cloud プロジェクト** で作り直し、GitHub の Secrets `YOUTUBE_API_KEY` に入れる（業スー酒場と無料枠を取り合わないため）
