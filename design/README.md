# デザインの素材

| ファイル | 中身 |
|---|---|
| `hero-slides.md` | 背景のスライドショーの思い・場面・ChatGPT へのプロンプトとやりとりの記録 |
| `slide-tokyo.webp`・`slide-kyoto.webp`・`slide-fuji.webp`・`slide-slope.webp` | 採用した背景の絵（ChatGPT で作成）。`-v1` などは途中の絵 |
| `logo-candidates.html` | ロゴ案6つ。ページ上部は A、アイコンは C を採用（2026-11-09） |

ページで使う形（`site/assets/`）は `scripts/make_assets.py` で作る。ロゴの文字は Archivo Black（SIL Open Font License、npm の `@fontsource/archivo-black`）を線（アウトライン）にしたもの。フォントのファイルはリポジトリに入れていない。
